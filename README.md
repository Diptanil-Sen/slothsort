# SlothSort
Lazy file tidier: Gemma (running locally in Ollama) suggests folders and clean names for a messy folder.
You review, press one button, and it moves files. Nothing is deleted, and the last tidy-up can be undone.
Run: pip install -r requirements.txt && python -m uvicorn app:app --port 8003  (open http://127.0.0.1:8003)
